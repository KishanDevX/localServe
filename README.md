# LocalServe MVP

A simple local-services marketplace connecting customers with nearby service providers.

## Preview

[Open the LocalServe MVP](https://local-serve-theta.vercel.app/)

## Features

- Search providers by service and locality
- Compare fees, ratings, and availability
- View provider details and submit sample requests
- Provider dashboard to edit profiles and manage availability
- Responsive interface

## Status

Frontend prototype with sample data. Authentication, database
storage, real bookings, and offline synchronisation are not
implemented yet.
